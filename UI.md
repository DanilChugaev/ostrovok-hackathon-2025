- `/` - главная страница приложения
  - Отображает общую информацию о программе "Секретный гость", отзывы, доступные отели или призыв к действию для подачи заявки
- `/health` - проверка состояния приложения
  - Возвращает JSON с информацией о работоспособности сервера (используется для healthcheck в Docker)
- `/login` - страница авторизации
  - Позволяет пользователям войти в систему, указав имя пользователя и пароль
- `/submit-request` - страница подачи заявки на участие в программе "Секретный гость"
  - Содержит форму для ввода личных данных, опыта и предпочтений
- `/profile` - личный кабинет пользователя
  - Отображает информацию о пользователе, его поездки, отчёты и статус лояльности
- `/admin` - панель администратора
  - Предоставляет интерфейс для управления заявками, отчётами и пользователями (доступно только для роли admin)
- `/hotel-account` - личный кабинет отеля
  - Позволяет представителям отелей просматривать отчёты и статистику по своим объектам (доступно для роли hotel)
- `/hotels` - список отелей
  - Показывает доступные отели с фильтрами по названию, городу и звёздам для выбора в рамках программы
- `/hotel-reports` - список отчётов пользователя
  - Отображает созданные отчёты с информацией о поездках и общем балле
- `/hotel-report?reportId=` - cтраница конкретного отчёта
  - Показывает детали отчёта, включая поездку, комментарий и прогресс заполнения
- `/hotel-report/stages?reportId=` - список этапов отчёта
  - Показывает этапы (например, заселение, бронирование) с прогрессом их заполнения
- `/hotel-report/stages/categories?reportId=&stageId=` - список категорий для этапа отчёта
  - Отображает категории (например, онлайн-бронирование) с прогрессом их оценки
- `/hotel-report/stages/categories/criteria?reportId=&stageId=&categoryId=` - список критериев для категории
  - Позволяет пользователю оценить критерии (например, удобство интерфейса), добавить комментарий и медиа
- `/404` - Страница ошибки 404
  - Отображается, если маршрут не найден, с перенаправлением для всех несуществующих путей
